# dartpad_main.dart

**Purpose:** Contains a self-contained, single-file edition of TypeStudio structured specifically for running inside the browser-based DartPad sandbox.

**How it works:** Bundles essential state, UI widgets, and models into one runnable file to accommodate environments that do not support multi-file project structures.

**Key components:** `main()`, `TypeStudioApp`, `FontApiConfig`, `AppTheme`, `FontService`, `AppState`
