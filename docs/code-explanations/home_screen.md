# home_screen.dart

**Purpose:** Provides the editorial dashboard screen displaying hero animations, active font highlights, popular font shelves, and typography hierarchy ramps.

**How it works:** Combines entrance fade and slide animations with a cycling headline timer and allows users to browse popular fonts horizontally.

**Key components:** `HomeScreen`, `_HomeScreenState`, `_buildHero`, `_buildFontShelf`, `_buildTypographyRamp`
