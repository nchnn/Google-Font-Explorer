# typography_controls_card.dart

**Purpose:** Houses interactive typography controls for font size, weight, leading, tracking, and text alignment.

**How it works:** Builds precision sliders with numeric readouts, discrete weight snapping rails, and alignment segmented controls that update PreviewState.

**Key components:** `TypographyControlsCard`, `_buildCustomSlider`, `_buildPrecisionRail`, `_buildFontWeightSection`, `_buildAlignmentSection`
