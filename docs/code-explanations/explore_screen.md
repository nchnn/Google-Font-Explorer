# explore_screen.dart

**Purpose:** Provides a searchable and filterable font explorer connecting directly to the Google Fonts API catalogue.

**How it works:** Handles debounced search queries, category chip filtering, multi-order sorting, sticky pinned headers, and incremental batch pagination.

**Key components:** `ExploreScreen`, `_ExploreScreenState`, `_rebuildResults`, `_sortEntries`, `_loadMoreEntries`
